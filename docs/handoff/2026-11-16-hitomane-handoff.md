# 引き継ぎ：ヒトマネ入稿ツール（hitomane_agent）

2026-11-16 時点。前の担当（Claude の別セッション）から引き継ぐための資料です。

## 1. 何を作っているか

求人媒体「ヒトマネ（HITO-Manager）」への **入稿と取り下げを、ボタン操作で自動にするツール** です。
同じ利用者のために、Q-mate 向けの同じ種類のツール（`qmate_agent/`）がすでに動いていて、それのヒトマネ版を作っています。

- 今の手作業：ヒトマネ用の GAS（③予約リストを一括実行）で「ヒトマネ出力_…」シートを作る → ⑤で検品 →
  CSV にしてヒトマネ管理画面で「ファイル取込予約」。取り下げは、担当者が件数を確かめて手で行う（全体で5万件が上限）。
- 目標：Q-mate 版と同じく、操作画面から「チェック → 入稿」「確認 → 取り下げ」をできるようにする。
- 最終的には Q-mate 版と1つのツールに統合したい。今は利用者の選択で、**ヒトマネ用の別ツール**として作っている。

## 7. ヒトマネ管理画面について分かっていること

- URL：`https://kanri.hitomgr.jp/m66w/`。**決まったネットワークからしか開けない**。クラウドの作業環境からはブラウザでも 403。
  マニュアルサイト（manual.hitomgr.jp）も、管理画面のログインを通すので同じく開けない。画面の作りは、利用者のスクリーンショットと画面調査の結果で知る。
- 1つのアカウント（m66w）で全社の原稿を扱う。一覧の会社名は「CB株式会社(B001)」の形（拠点名(拠点コード)）。今「全50000件」（上限）。
- 取り込み：トップの「ファイルを取込む」か、募集管理の「ファイル取込予約」→ ダイアログ「募集情報のファイルを取り込む（新フォーマット）」→
  「ファイルを選択」→「ファイル取込予約」。「既存原稿と同じ募集番号の原稿を上書きせずに取り込む」は外したまま（同じ募集番号は上書き）。
- 取り出し：トップの「募集管理」→ 検索欄（フリーワード＋項目、掲載開始日〜、掲載終了日〜、雇用形態、ステータス：掲載のみ／非掲載のみ、
  その他：旧フォーマット原稿のみ・最低賃金下回り原稿のみ）→「検索」→「ファイル取出予約」。
- 予約一覧：「ファイル取出予約」を押すと開く。列はリクエスト日時・データ種別（募集管理（新）など）・ステータス（待機中 → 完了）・詳細
  （取出しファイルのリンク、全N件、処理時間）・削除予定日。「最新を表示する」で更新。キャンセルもできる。**取り込みの結果・エラーもここに出る。**
- 取り下げの手順（利用者の手作業）：取り出した CSV の **開始日・終了日を2年くらい前の日付**、**ステータスを「非掲載」** に書き換えて取り込む。
  終了日が未来のままだと、非掲載にしても残り続ける（ヒトマネは入れた日から1年後を終了日にする）。2年前にしておくと表示されず、放っておくと削除扱いになる。
  旧フォーマットの原稿も同じ方法で落としている。
- 設計で決めたこと：開始日・終了日は両方「実行した日の2年前の日」。会社は土台の会社情報マスターの拠点コードで選び、取り出したあと拠点コードが合う行だけ書き換える。
  取り下げは自動ではやらない（担当者が条件と件数を確かめてから）。「確認だけ」のあと同じ日・同じ条件で取り下げるときは、取り出しを省いてそのファイルを使う（Q-mate 版と同じ）。
  入れる件数を足すと5万件を超えるときは、確認画面で知らせる（止めない）。1万行を超えるシートは1万行ずつに分けて取り込む。
